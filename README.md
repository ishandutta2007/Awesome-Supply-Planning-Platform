## 🌐 Top Supply Planning Platform Tools Ecosystem

**Curated List of SaaS/Commercial Products & Open-Source GitHub Projects**  
*Focused on Advanced Planning & Scheduling (APS), Demand & Supply Planning, S&OP/IBP, Inventory Optimization & Production Scheduling*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Supply Planning**. These tools help manufacturers and supply chain teams balance demand and supply, optimize inventory, schedule production against constraints, run what-if scenarios, and support Sales & Operations Planning (S&OP) or Integrated Business Planning (IBP) processes.

**Examples** include Kinaxis RapidResponse, RELEX Solutions, Blue Yonder Supply Planning, ToolsGroup, Anaplan, OMP Unison Planning, PlanetTogether, Arkieva, John Galt Solutions, and Logility (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted APS, MRP, production scheduling, and supply chain planning — ideal for manufacturers and teams that want constraint-based planning without enterprise licensing costs.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites. 🤝

## 🔓 Open-Source GitHub Projects

- **[odoo/odoo](https://github.com/odoo/odoo)** <a href="https://github.com/odoo/odoo/stargazers"><img src="https://img.shields.io/github/stars/odoo/odoo?style=social&color=white" alt="GitHub stars"/></a>  
  Modular open-source ERP whose manufacturing apps support BOMs, work orders, basic MRP, quality, and maintenance.

- **[facebook/prophet](https://github.com/facebook/prophet)** <a href="https://github.com/facebook/prophet/stargazers"><img src="https://img.shields.io/github/stars/facebook/prophet?style=social&color=white" alt="GitHub stars"/></a>  
  Tool for producing high quality forecasts for time series data that has multiple seasonality with linear or non-linear growth.

- **[frappe/erpnext](https://github.com/frappe/erpnext)** <a href="https://github.com/frappe/erpnext/stargazers"><img src="https://img.shields.io/github/stars/frappe/erpnext?style=social&color=white" alt="GitHub stars"/></a>  
  Fully open-source ERP with strong manufacturing and MRP modules, including multi-level BOMs and capacity-related features.

- **[google/or-tools](https://github.com/google/or-tools)** <a href="https://github.com/google/or-tools/stargazers"><img src="https://img.shields.io/github/stars/google/or-tools?style=social&color=white" alt="GitHub stars"/></a>  
  Powerful open-source optimization library widely used to build custom supply and production planning solvers.

- **[Pyomo/pyomo](https://github.com/Pyomo/pyomo)** <a href="https://github.com/Pyomo/pyomo/stargazers"><img src="https://img.shields.io/github/stars/Pyomo/pyomo?style=social&color=white" alt="GitHub stars"/></a>  
  An object-oriented algebraic modeling language in Python for structured optimization models.

- **[TimefoldAI/timefold-solver](https://github.com/TimefoldAI/timefold-solver)** <a href="https://github.com/TimefoldAI/timefold-solver/stargazers"><img src="https://img.shields.io/github/stars/TimefoldAI/timefold-solver?style=social&color=white" alt="GitHub stars"/></a>  
  Open-source constraint solver and planning engine excellent for building custom finite scheduling and resource allocation apps.

- **[coin-or/pulp](https://github.com/coin-or/pulp)** <a href="https://github.com/coin-or/pulp/stargazers"><img src="https://img.shields.io/github/stars/coin-or/pulp?style=social&color=white" alt="GitHub stars"/></a>  
  An LP modeler written in Python for optimization.

- **[frePPLe/frepple](https://github.com/frePPLe/frepple)** <a href="https://github.com/frePPLe/frepple/stargazers"><img src="https://img.shields.io/github/stars/frePPLe/frepple?style=social&color=white" alt="GitHub stars"/></a>  
  Leading open-source supply chain planning and APS tool. Provides demand forecasting, constraint-based production planning and scheduling.

- **[msupply-foundation/open-msupply](https://github.com/msupply-foundation/open-msupply)** <a href="https://github.com/msupply-foundation/open-msupply/stargazers"><img src="https://img.shields.io/github/stars/msupply-foundation/open-msupply?style=social&color=white" alt="GitHub stars"/></a>  
  Domain-focused open-source logistics management information systems (e.g., open mSupply).

- **[IBM/CMMPPT](https://github.com/IBM/CMMPPT)** <a href="https://github.com/IBM/CMMPPT/stargazers"><img src="https://img.shields.io/github/stars/IBM/CMMPPT?style=social&color=white" alt="GitHub stars"/></a>  
  Open-source constrained materials management and production planning components for optimal resource allocation.

### 💡 Additional Strong Open-Source Options

- Custom planning models built with PuLP, Pyomo, or other Python optimization stacks.
- Integration of forecasting libraries (Prophet, statsmodels, etc.) with ERPNext/Odoo or frePPLe.
- Research and academic APS/scheduling prototypes available on GitHub.
- Spreadsheet-to-optimizer workflows and lightweight scenario engines for smaller operations.

**Frameworks for building custom systems**: Start with **frePPLe** for a ready-to-run open-source APS experience. Use **ERPNext** or **Odoo** when you need planning tightly integrated with broader ERP processes. For advanced or highly customized finite scheduling, combine **Timefold** or **OR-Tools** with your own data model and UI. Layer forecasting and inventory optimization logic on top of these foundations.

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Supply planning at enterprise scale involves complex constraints, multi-echelon networks, and high data quality requirements. Open-source tools (especially frePPLe and ERP/MRP modules) are capable for many manufacturing use cases but may require more configuration, integration, and algorithmic tuning than mature commercial APS platforms.
- Always validate planning results against business rules, capacity realities, and financial impact before operational use.
